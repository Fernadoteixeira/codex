---
name: code-breaking-changes
description: Breaking changes
---

Pesquise alterações que causam incompatibilidade em interfaces de integração externas:

- APIs do servidor de aplicativos
- Parâmetros da CLI
- carregamento da configuração
- retomando sessões de implantações existentes

Não pare depois de identificar um problema; analise todas as formas possíveis pelas quais podem ocorrer alterações que causem incompatibilidade.
