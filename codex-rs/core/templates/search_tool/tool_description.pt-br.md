# Descoberta de ferramentas de aplicativos (conectores)

Realiza pesquisas nos metadados da ferramenta de aplicativos/conectores usando o BM25 e apresenta as ferramentas correspondentes para a próxima chamada do modelo.

Você tem acesso a todas as ferramentas dos seguintes aplicativos/conectores:
{{app_descriptions}}
É possível que algumas das ferramentas não tenham sido fornecidas a você inicialmente; portanto, você deve usar esta ferramenta (`tool_search`) para localizar as ferramentas necessárias e carregá-las para os aplicativos mencionados acima. Para os aplicativos mencionados acima, use sempre `tool_search` em vez de `list_mcp_resources` ou `list_mcp_resource_templates` para a descoberta de ferramentas.
